4.2 API message specification

The API messages supported by HBee24 are described in this section.

API type ID 0x01: Set Coordinator (command)

  • Direction: Host → HBee24 (Coordinator)
  • This API message determines the operation mode of the network coordinator.
  • HBee24 operates in two modes: Install mode and Operation mode.
  • New devices can join the network in Install mode, but not in Operation mode.
  • The host may allow new devices to join the network during operation by changing the mode from Operation mode to Install mode.
Field Description
API Type ID 0x01
Message Name Set Coordinator
Message Type Command
Direction Host → HBee24 (Coordinator)
Mode 1 Install mode
Mode 2 Operation mode
Join Permission Allowed only in Install mode
Note To allow a new device to join during operation, the host must switch the coordinator to Install mode.
